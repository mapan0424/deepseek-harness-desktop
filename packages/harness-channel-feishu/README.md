# `@anarkhgatsby/deepseek-harness-channel-feishu`

Feishu/Lark channel plugin for DeepSeek Harness. It uses the Feishu long connection mode and the shared Harness channel core.

```bash
dsh plugin --profile web add @anarkhgatsby/deepseek-harness-core
dsh plugin --profile web add @anarkhgatsby/deepseek-harness-channel-feishu
```

After installation, configure the Feishu App ID and App Secret in the visual channel configuration page.
