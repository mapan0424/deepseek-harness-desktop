# `@anarkhgatsby/deepseek-harness-channel-config`

Adds a visual configuration page for DeepSeek Harness channels, including Feishu/Lark and other supported channel settings.

```bash
dsh plugin --profile web add @anarkhgatsby/deepseek-harness-channel-config
```

The page only configures channels whose runtime plugins are installed. Install the Feishu package separately to use Feishu.
